📝 How to Update Password in Google Sheets:

  1. Click "Generate Password Hash" above
  2. Copy the generated hash
  3. Open your Google Sheet (click button above or use link)
  4. Go to the "Users" tab
  5. Find the user's email row
  6. Paste the hash in the "Password Hash" column
  7. Inform the user of their new password
