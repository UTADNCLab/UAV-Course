📋 What is this?

This tool generates password hashes that you can manually update in the Google Sheets "Users" tab. Use this when a user forgets their password and needs a manual reset.

📝 How to Update in Google Sheets:

  1. Copy the generated hash above
  2. Open your Google Sheet
  3. Go to the "Users" tab
  4. Find the user's email row
  5. Paste the hash in the "Password Hash" column
  6. Tell the user their new password
