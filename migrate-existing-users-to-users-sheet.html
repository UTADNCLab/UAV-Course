🔄 Migrate Existing Users

Add users from Progress sheet to Users sheet

📋 What This Tool Does:

Problem: Some users (like Yan Wan) appear in the "Progress" sheet but NOT in the "Users" sheet. This happened because they were added before the new registration system.

Solution: This tool will:

  • Find all users in "Progress" sheet
  • Check if they exist in "Users" sheet
  • Create accounts for missing users
  • Set a default password you specify

⚠️ Important:

You'll need to tell migrated users their temporary password so they can login. They should change it after first login.

This password will be set for all users who don't have accounts yet.
