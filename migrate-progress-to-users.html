🔄 Migrate Progress to Users

Automatically copy user data from Progress sheet to Users sheet

📋 What This Tool Does:

This tool will:

  • Read user data from your Progress sheet
  • Extract email addresses and names
  • Create entries in the Users sheet
  • Enable cross-device login for existing users

⚠️ Important Notes:

  • You need to provide passwords for each user (they'll be hashed)
  • This is a one-time migration
  • Existing entries in Users sheet won't be duplicated
