HOW FILES WORK TOGETHER
========================

1. Student opens → index.html
2. HTML loads → styles.css (makes it pretty)
3. HTML loads → course.js (makes it work)
4. course.js loads → course-data.json (gets content)
5. course.js loads → quiz.js (for quizzes)
6. course.js loads → progress.js (tracks progress)
7. Everything works together! ✨

COMMON TASKS
============

Add Video:
  1. Get YouTube video ID
  2. Open course-data.json
  3. Find "videoUrl"
  4. Replace with: https://www.youtube.com/embed/YOUR_ID

Change Quiz:
  1. Open course-data.json
  2. Find "questions" array
  3. Edit question text, options, answers
  4. Save and refresh

Change Colors:
  1. Open css/styles.css
  2. Find :root section
  3. Change color values
  4. Save and refresh

Deploy:
  1. Read DEPLOYMENT_GUIDE.md
  2. Choose platform (GitHub Pages recommended)
  3. Upload files
  4. Get your URL!


TROUBLESHOOTING
===============

Problem: Videos not showing
Solution: Check videoUrl format, use embed URL

Problem: Progress not saving
Solution: Enable localStorage, use HTTPS

Problem: Quiz not working
Solution: Check correctAnswer is 0-3, validate JSON

Problem: Styling broken
Solution: Clear cache (Ctrl+F5), check CSS file

Problem: JSON errors
Solution: Validate at jsonlint.com
