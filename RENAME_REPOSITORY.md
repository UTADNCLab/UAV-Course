## 📋 Steps to Rename Repository:

### **Step 1: Rename on GitHub**

1. Go to your repository: https://github.com/jaymehta12110/UAV-Course
2. Click **Settings** (top right)
3. Under "Repository name", change `UAV-Course` to `OpenCourseLearning`
4. Click **Rename**

**⚠️ Important:** GitHub will automatically redirect old links to the new name!

---

### **Step 2: Update Local Repository**

Open your terminal/command prompt and run:

```bash
cd c:/Users/2810j/OneDrive/Desktop/course
git remote set-url origin https://github.com/jaymehta12110/OpenCourseLearning.git
```

---

### **Step 3: Verify GitHub Pages**

1. Go to: https://github.com/jaymehta12110/OpenCourseLearning/settings/pages
2. Confirm "Source" is set to: **Deploy from a branch** → **main** → **/ (root)**
3. Your site will be live at: `https://jaymehta12110.github.io/OpenCourseLearning/`
