---

### **Step 2: Configure DNS**

After buying domain, add this DNS record:

```
Type: CNAME
Name: www
Value: jaymehta12110.github.io
TTL: Automatic
```

**For root domain (opencourse.com), add these A records:**
```
Type: A, Name: @, Value: 185.199.108.153
Type: A, Name: @, Value: 185.199.109.153
Type: A, Name: @, Value: 185.199.110.153
Type: A, Name: @, Value: 185.199.111.153
```

---

### **Step 3: Configure GitHub Pages**

1. Go to: https://github.com/jaymehta12110/UAV-Course/settings/pages
2. Under "Custom domain", enter: `www.opencourse.com` (or your domain)
3. Click **Save**
4. Wait 5 minutes
5. Check **"Enforce HTTPS"**

---

### **Step 4: Wait for DNS**

- DNS changes take 1-24 hours
- Usually works within 1-2 hours
- Check at: https://www.whatsmydns.net

## ❓ Common Questions:

### Q: Can I get a free custom domain?
**A:** No professional free domains exist. Free domains (`.tk`, `.ml`) look unprofessional.

### Q: Do I have to pay every year?
**A:** Yes, domains are rented yearly. Most registrars auto-renew.

### Q: What if my desired domain is taken?
**A:** Try variations:
- `opencourselearning.com`
- `theopencourse.com`
- `myopencourse.com`
- `opencourse.io` (more expensive, ~$30/year)

### Q: Can I use my domain for other things too?
**A:** Yes! You can use subdomains:
- `course.yourdomain.com` → GitHub Pages
- `blog.yourdomain.com` → WordPress
- `mail.yourdomain.com` → Email

### Q: Will my current links break?
**A:** No! GitHub automatically redirects old URLs to your new domain.
