# 🔧 Fix 404 Error - Enable GitHub Pages

You're getting a 404 because GitHub Pages isn't enabled yet. Here's how to fix it:

---

## 🚀 Quick Fix (2 Minutes)

### Step 1: Go to Repository Settings

1. Open: https://github.com/jaymehta12110/uav-course
2. Click the **"Settings"** tab (top right)

### Step 2: Enable GitHub Pages

1. In the left sidebar, scroll down and click **"Pages"**
2. Under **"Source"**:
   - Click the dropdown that says "None"
   - Select **"main"** (or "master")
   - Keep **"/ (root)"** selected
3. Click **"Save"**

### Step 3: Wait 2-3 Minutes

GitHub needs time to build your site. You'll see a message:
```
Your site is ready to be published at https://jaymehta12110.github.io/uav-course/
```

### Step 4: Visit Your Site

After 2-3 minutes, go to:
```
https://jaymehta12110.github.io/uav-course/landing.html
```

## ❓ Still Getting 404?

### Check These:

1. **Is the repository public?**
   - Go to Settings → scroll to bottom
   - Should say "Public" not "Private"

2. **Did you wait 2-3 minutes?**
   - GitHub needs time to build
   - Refresh after waiting

3. **Is the branch correct?**
   - Should be "main" not "master"
   - Check in Settings → Pages

4. **Are files pushed?**
   - Go to https://github.com/jaymehta12110/uav-course
   - You should see all your files listed

---

## 🔄 If Still Not Working

Try this:

1. Go to repository: https://github.com/jaymehta12110/uav-course

3. See if any workflows are running
4. Wait for them to complete
5. Then try your URL again
